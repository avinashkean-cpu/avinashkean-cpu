## 2. Statement of Work (SOW) & Vendor Governance

### 2.1 SOW Drafting Standards
- **Explicit Scope Boundaries:** What is in-scope vs. out-of-scope (e.g., application code refactoring vs. containerization).
- **Milestone-Based Deliverables:** Linking commercial payout schedules to verified acceptance criteria (e.g., UAT sign-off, security penetration test clearance).
- **Vendor Escalation Matrix:** Multi-tier SLA response matrix (`Level 1` Engineer ➔ `Level 2` Tech Lead ➔ `Level 3` Principal Architect ➔ Executive Sponsor).
- **Principle of Least Privilege (PoLP):** Enforcing Just-In-Time (JIT) access for third-party vendor engineers with session recording and automated credential rotation.
